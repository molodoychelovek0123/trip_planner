# Отчет о возможности парсинга авиабилетов (Flights Scraping Report)

В рамках задачи было проведено исследование возможности создания краулера для агрегации авиабилетов с популярных сервисов: Booking, Trip.com, Т-Путешествия, Яндекс Путешествия, Ozon Travel и Aviasales.

## Результаты исследования

Попытки автоматизированного сбора данных (с использованием `urllib`, `Playwright` и headless-браузеров) показали, что **ни один из указанных сервисов не может быть надежно подключен** без использования сложных систем обхода антифрод-защиты.

Все целевые платформы используют агрессивную защиту от ботов и парсинга (WAF, Cloudflare, DataDome и другие анти-бот системы).

### Детали по каждому сервису:

1. **Яндекс Путешествия**
   - Строгая защита от ботов (SmartCaptcha). При попытке зайти через headless-браузер мгновенно выдается страница с капчей.

2. **Aviasales**
   - Возвращает контент, в котором присутствует блокировка ботов (Cloudflare Turnstile/капча).
   - Публичные эндпоинты партнерских API (Travelpayouts) требуют авторизации, и без официального одобренного API-ключа возвращают `401 Unauthorized`.

3. **Booking.com (Flights)**
   - Блокирует автоматические запросы, возвращая статус `202` (Accepted) или заглушки вместо реального контента, требуя прохождения проверки (JavaScript/капча).

4. **Т-Путешествия (Tinkoff)**
   - Полностью закрыт для парсинга, возвращает страницы-заглушки или страницы с требованием пройти проверку на человечность (капча).

5. **Ozon Travel**
   - Защищен Cloudflare (статус `403 Forbidden` для ботов). Страница требует JavaScript challenge и не отдает данные при парсинге.

6. **Trip.com**
   - Нестандартные коды ответа при обнаружении headless-браузера (например, код `432`) и блокировка доступа к результатам поиска.

## Вывод

Согласно требованиям: *"Если нет возможности подключить хоть один сервис, то заканчивай с этой идеей и напиши md почему нет возможности"*.

Разработка и поддержка собственного краулера для этих сайтов в текущих условиях нецелесообразна и невозможна минимальными усилиями. Любой парсинг будет регулярно ломаться из-за обновления защиты от ботов. Для легального и стабильного получения данных об авиабилетах необходимо использовать официальные партнерские API (например, Travelpayouts для Aviasales), которые требуют регистрации юрлица, модерации проекта и получения API-ключей.

В связи с вышеизложенным, идея подключения краулера авиабилетов отменена.
